# Портфолио Никиты Резепова

Персональный сайт-портфолио видеомонтажёра: главная страница с услугами и контактами, а также отдельный архив реальных проектов.

## Локальная разработка

```bash
npm install
npm run dev
```

Vite выведет локальный адрес в терминале. Основные маршруты:

- `/` — главная страница;
- `/projects` — полный архив проектов.

## Проверка

```bash
npm run lint
npm run build
```

Проект использует React, TypeScript, Vite, React Router, Tailwind CSS и Framer Motion. Конфигурация `vercel.json` направляет клиентские маршруты в `index.html`, поэтому прямое открытие и обновление `/projects` работает как для SPA.
